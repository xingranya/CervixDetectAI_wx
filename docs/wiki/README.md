## 阅读建议

- 第一次接触项目：先看 01，再看 02 建立全局视角。
- 只想改前端：从 03 开始，关注 `utils/` 公共模块。
- 只想改后端：从 04 开始，重点看 `services/` 与 `repositories/`。
- 对接接口：直接看 06，配合 05 的字段定义。
- 上线、调试、打包：看 07。

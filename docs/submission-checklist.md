# 微信小程序提审填写清单

## 后台类目

```text
工具 / 健康管理
```

不要填写：

- 医疗服务 / 就医服务
- 医疗服务 / 就医服务 / 查报告单
- 医疗服务 / 互联网医院
- 医疗服务 / 其他医学健康服务
- 政务民生 / 医疗

## 基本资料

- 小程序名称：云端智诊
- 小程序简称：云端智诊
- 功能介绍：女性用户的健康管理助手，记录检查摘要、管理复查提醒、整理就诊前问题。产品仅用于健康信息记录与提醒，不提供在线诊断、治疗或问诊服务。
- 标签建议：健康管理、记录、提醒、女性健康

## 审核截图建议

- 首页：显示“最近检查摘要、复查提醒、检查记录、问题整理”，并能先浏览功能，不出现首屏强制登录。
- 检查记录：显示健康检查摘要列表。
- 复查提醒：显示复查计划和标记完成按钮。
- 问题整理：显示就诊前问题清单。
- 健康知识：显示文章列表，并可打开文章正文。
- 我的：显示隐私说明、合规与服务边界、意见反馈入口。

## 开发配置自查

- `miniprogram/project.config.json` 中 `urlCheck` 应保持开启。
- 体验版和正式版接口必须使用 HTTPS，并在微信后台配置 request 合法域名。
- 如需微信服务通知，在 `miniprogram/config/app.js` 中填写订阅消息模板 ID 后再提审。
- 小程序隐私保护指引中需声明头像、昵称、健康记录、提醒、反馈等用途；头像和昵称为选填，不应写成必填条件。
- 首页首屏不得直接要求手机号、头像、昵称授权登录；应先让用户浏览首页与主要功能，再由用户自行选择登录。
- 提审时优先录制“首页浏览 -> 健康知识 -> 隐私说明 -> 返回首页 -> 主动进入登录页”的操作视频，更符合本次整改口径。

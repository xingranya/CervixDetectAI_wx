# 小程序类目填写说明

## 结论

当前个人主体建议填写：

```text
工具 / 健康管理
```

理由：

- 微信官方个人主体开放类目中包含“工具 / 健康管理”，适用范围是身高、体重等健康管理记录。
- 本小程序首版功能被设计为健康信息记录、提醒和问题整理，能与该类目保持一致。
- 个人主体不适合申报医疗服务类目；医疗服务、查报告单、互联网医院等方向通常需要医疗机构或平台资质。

## 提审版功能边界

可以出现：

- 健康检查摘要记录
- 复查提醒
- 就诊前问题整理
- 女性健康知识
- 隐私说明
- 合规与服务边界
- 用户反馈

避免出现：

- AI 辅助诊断
- 在线问诊
- 医疗报告单官方查询
- 医生诊疗建议
- 挂号、缴费、处方、药品、医疗器械交易
- 医院官方服务暗示
- 通过上传图片自动识别病变

## 账号资料建议

- 小程序名称：云端智诊
- 小程序简称：云端智诊
- 服务标签：健康管理、记录、提醒、女性健康
- 简介：女性用户的健康管理助手，记录检查摘要、管理复查提醒、整理就诊前问题。产品仅用于健康信息记录与提醒，不提供在线诊断、治疗或问诊服务。

## 首页必须体现

微信运营规范要求核心功能在首页体现。首页至少展示：

- 最近一次检查摘要
- 下次复查提醒
- 检查记录入口
- 复查提醒入口
- 问题整理入口
- 健康知识入口
- “仅用于健康管理记录”的说明
